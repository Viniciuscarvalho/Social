## 🎓 Aprendizados e Decisões

### ButtonStyle vs Custom Views
Optamos por usar `ButtonStyle` para botões porque:
- Mantém o comportamento nativo de acessibilidade
- Animações automáticas de pressed state
- Melhor performance
- API mais limpa com extensions

### ViewBuilder para Composição
Uso extensivo de `@ViewBuilder` para:
- Máxima flexibilidade nos componentes
- Composição natural estilo SwiftUI
- Redução de código boilerplate

### Conditional Modifiers
Criamos helper `conditionalModifier` para aplicar modifiers condicionalmente sem repetir código.

### Skeleton Loading
Implementação de skeleton com animação shimmer usando:
- `LinearGradient` animado
- `@State` para controle de animação
- Performance otimizada com `.repeatForever()`

### Enums para Variações
Uso de enums para variantes de componentes:
- Type-safe
- Autocomplete no Xcode
- Fácil extensão futura
